**Interpretation:** By the section 13.3 table this is **trace used, steps, gain over start-last CODI** ("forced rollout adds real depth"). Each latent decides the answer alone, different latents hold different steps, and level L needs L-1 passes (one per trained step, plus one more for full accuracy below L7), which start-last CODI never showed. What a latent holds matches the decoder's step text: z_j carries the operand v_j almost perfectly (.97-1.00) and the result v_{j+1} at about .8 by a linear probe, while the swap shows v_{j+1} is fully set by z_j. So the latent holds the step `<<v_j op b =`, the next pass computes the result, and the next latent carries it as its operand. Readings of the decoded trace are faithful in the causal sense used here: change what the latent says and the answer changes as the trace predicts. The untrained latent after the last step carries v_{L-1} (probe 1.00 at L6) and the answer tokens apply the last rule, as the out-of-range pattern in 20261107-225709 showed. z_0 is only partly a clean carrier: it is computed from the question, and a third of its swaps end elsewhere.
**Gotchas hit:** The checkpoint includes decoder weights; `load_state_dict(strict=False)` drops them because the local CODI has no `step_decoder` field, and the clean run confirms the answer path is unchanged.
**Caveats:** One seed, valid only (test is reserved for the main record). The "next latent" probe cell was read after the pre-registered cells, so it is post hoc, though it sits in the pre-registered grid. Teacher-forced decoding is not used here; probes are frozen and linear. Mean ablation is the draft's necessity measure, and the swap is the stronger test. The step loss could also have improved the ordinary single pass, but the pass sweep rules that out as the source of the gain: with fewer passes than steps accuracy is at chance.
