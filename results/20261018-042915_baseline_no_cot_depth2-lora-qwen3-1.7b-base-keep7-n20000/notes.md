**Headline results:** per level 1 -> 0.07, 2 -> 0.05, 3 -> 0.03, 4 -> 0.02; final training loss 0.89.
**Interpretation:** Depth curve: k=7: L1 0.07 / L2 0.05 (final train loss 0.89); k=14: 0.14 / 0.07; k=21: 0.90 / 0.13 (loss 0.65); k=28 (full model, run 20261018-041131 n=20000): 1.00 / 0.88, L3 0.21 (loss 0.41). Read naively it is a staircase (7-14 layers: nothing, 21: one rule, 28: two rules and some of three), but the 7- and 14-layer models fail even one rule, which the full model learns from 1k examples, and their training loss stays high. One rule does not plausibly need 21 layers, so the shallow failures mostly measure that cutting late pretrained layers removes skills (arithmetic, mapping to output tokens) a rank-16 adapter cannot rebuild, not a serial-depth limit. The informative contrast is 21 vs 28 (both do one rule; only 28 does two), but even that is confounded by what the removed layers knew. Suggestive of depth mattering for composition, not a clean test.
**Gotchas hit:** none beyond the earlier LoRA runs (PEP 668 venv).
**Caveats:** One seed, one recipe tuned for nothing; LoRA rank 16 on a truncated model may be the bottleneck (full fine-tuning or higher rank might recover more); 2 epochs only; 200 test items per level. Truncation keeps the earliest layers, so 'depth' here also means 'which pretrained layers survive'.
