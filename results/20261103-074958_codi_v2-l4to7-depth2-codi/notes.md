**Interpretation:** The main result is that neither model learned the task without written steps in 6.25k steps: the no-CoT path stays near floor while the teacher path is perfect. Round 1 at epoch 12 (9.4k steps, accidental eval 20261101-235727) had L2 0.90 / L3 0.45 / L4 0.11, so student skill on hard levels came after the easy levels were learned; removing levels 1-3 likely removed the scaffold, not a shortcut. Within that floor, CODI does beat CODI-0 significantly (round 1 had no gain), but the sweep shows most of it with a single latent (k=1 0.059 vs CODI-0 0.043) and only +0.012 more from 5 further latents, so this is weak evidence for multi-step latent computation. Treat as: latents give a small, real edge at L4 when nothing else works; the setup does not test whether they carry rule-by-rule state.
