## 2026-11-08 — ProsQA codi route split: no latent carries anything (every site, every route, all sites .00); when one relation on the gold path is rewired so the answer flips, the model still gives its original answer .975 of the time (codi, run_id: 20261108-093050_codi_prosqa-grid-route-split)

**Goal:** Necessity check on grid ProsQA codi; pre-registered (t17, commit 3574431): every condition <= .03, fails the check (ignored regime; t16 need = 0).
**Mechanism / model:** `connordilgren/gpt2-prosqa-codi`, 6 latents.
**Data:** ProsQA test; minimal pairs from `scripts/necessity/pairs.py`: one relation on the gold path rewired to another concept of the same question so that the other option becomes reachable and the gold one not (checked by our reasoner, which reproduces gold on all 500 originals); equal token length; up to 1000 per path length (all 870 candidates used; many items have no flipping edit because the gold option stays reachable by another route). Qualified (recipient right, donor answered as implied): 18 / 870.
**Hyperparams / command:** `CHUNK=7 grid_split.py prosqa codi mps <out> 1000` (conditions in chunks of 7 rows: the first attempt with 28-row batches ran out of MPS memory on ~500-token questions); batched = single runs (agreement 1.000); raw `codi_audit_artifacts/t17_prosqa_codi.json`.
**Results:** all 24 single-site conditions and both all-site swaps .00 on the 18 qualified pairs. Edit sensitivity: of 720 recipients answered right, the edited question is answered as implied .025; the original answer is kept .975.
**Interpretation:** Fails the check, latents ignored, as predicted (with t16: 0 latents = 6 latents). The edit-sensitivity number is new and large: the model's ProsQA accuracy does not come from following the stated relations along the path; a one-relation rewiring that a path-follower must notice leaves its answer unchanged nearly always. Coconut's .98 is therefore not evidence of path search in this checkpoint, latent or not.
**Caveats:** edited graphs come from our rewiring, not the ProsQA generator, so they may break regularities the model learned (e.g. which subgraph the distractor option sits in); the result says the answer does not track the rewired relation, not which cue it uses. Only 18 qualified pairs, so the route-split rates have wide intervals (all zero).
